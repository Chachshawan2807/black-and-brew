# ☕ BLACK-AND-BREW ERP

> เว็บแอปจัดการร้าน **BLACK AND BREW** — ตารางงาน คลังสินค้า ออเดอร์เมล็ด และการซ่อมบำรุง อยู่ในที่เดียว เปิดจากมือถือหรือแท็บเล็ตในร้านได้ทันที

| | |
| --- | --- |
| **เวอร์ชัน** | 9.4 |
| **ภาษา** | ไทย |
| **การเข้าใช้** | PIN 6 หลัก |
| **ติดตั้งแอป** | รองรับ PWA — เพิ่มไปหน้าจอโฮมได้ |

---

## 🗂️ เมนูในแอป

| | หน้า | ทำอะไร |
| --- | --- | --- |
| 🏠 | **หน้าหลัก** | สรุปกะวันนี้–พรุ่งนี้ ว่าใครอยู่หน้าร้าน รายการที่ต้องสั่งซื้อ/รายการซ่อมบำรุงที่ต้องทำ |
| 📅 | **ตารางงาน** | จัดตารางการทำงาน วันหยุด วันลา ดึงวันหยุดนักขัตฤกษ์อัตโนมัติ |
| 📦 | **คลังสินค้า** | แก้ไขข้อมูลสต็อก บันทึกอัตโนมัติ ยกเลิก/ทำซ้ำได้ |
| 📋 | **ตรวจนับคลังสินค้า** | นับสต็อกจริงเท่านั้น |
| ☕ | **ออเดอร์เมล็ดกาแฟ** | สร้างออเดอร์ อัปโหลดสลิป ติดตามการชำระเงินและจัดส่ง |
| 📈 | **รายงานความแม่นยำ** | คะแนนความแม่นยำจากรายการที่นับตัวเลขจริง |
| 📊 | **แดชบอร์ดพนักงาน** | ดูภาพรวมเวลาทำงานของพนักงาน |
| 🚚 | **เบิกของสาขา 2** | เบิกหลายรายการในครั้งเดียว สต็อกอัปเดตทันที |
| 🔧 | **บันทึกการซ่อม** | บันทึกประวัติการซ่อมบำรุง |
| ⚙️ | **ตั้งค่า** | ประวัติเข้าใช้ ลายนิ้วมือ/ใบหน้า การแจ้งเตือน |

---

### 🔐 ความปลอดภัย

| ฟีเจอร์ | รายละเอียด |
| --- | --- |
| 🔢 PIN | 6 หลัก |
| 👆 Passkeys | ลงทะเบียนหลังใส่ PIN ครั้งแรก — เข้าครั้งถัดไปเร็วขึ้นด้วยการแสกนใบหน้าหรือนิ้วมือ |
| 🔔 Web Push | แจ้งเตือนสต็อก ตารางงานประจำวัน การรับเข้า-นำออก สินค้า และอื่นๆ |
| 📲 PWA | ติดตั้งบนหน้าจอโฮม ใช้ offline บางส่วนได้ |
