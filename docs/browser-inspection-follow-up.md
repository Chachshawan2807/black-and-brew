# Browser inspection follow-up

ตรวจหน้าจอจริงใน dev server วันที่ 22 ตุลาคม 2026

## หน้าที่ตรวจแล้ว

- หน้าหลัก `/th/home`
- ตารางงาน `/th/schedule`
- ออเดอร์เมล็ดกาแฟ `/th/bean-orders` และฟอร์มสร้าง `/th/bean-orders/new`
- คลังสินค้า `/th/inventory`
- ตรวจนับคลังสินค้า `/th/inventory/count`
- รายงานความแม่นยำ `/th/inventory/accuracy`
- เบิกของสาขา `/th/inventory/branch-withdraw`
- แดชบอร์ด `/th/dashboard`
- ตั้งค่า `/th/settings`
- บันทึกการซ่อม `/th/maintenance`
- รายละเอียดออเดอร์ `/th/bean-orders/[id]`
- แก้ไขออเดอร์ `/th/bean-orders/[id]/edit`

## จุดที่แก้แล้ว

1. **ตั้งค่า:** เปลี่ยน server snapshot ของ external store ให้คืน object เดิมทุกครั้ง แก้คำเตือน `getServerSnapshot` และตรวจหน้าตั้งค่าหลังโหลดแล้ว
2. **รายงานความแม่นยำ:** `<title>` ใช้ข้อความเดียว แก้คำเตือน children หลายส่วน
3. **รายละเอียดออเดอร์:** ตัดจังหวัดและรหัสไปรษณีย์ที่ซ้ำท้ายบรรทัดก่อนแสดง แล้วเติมกลับอย่างละหนึ่งครั้ง
4. **การโหลดหน้าแก้ไข:** ซ่อนฟอร์มจนกว่าจะมีรหัสและข้อมูลออเดอร์ครบ พร้อมกันการส่งฟอร์ม/บันทึกเมื่อข้อมูลเริ่มต้นยังไม่พร้อม

## สถานะการตรวจรอบล่าสุด

ตรวจซ้ำหลัง dev server กลับมาทำงาน: หน้าแก้ไขและรายละเอียดแสดงข้อมูลครบ ที่อยู่ไม่ซ้ำ และหน้าตั้งค่ากับรายงานความแม่นยำเปิดได้โดยไม่มี console error/warning หลังโหลดเสร็จ ก่อนหน้านี้เคยพบ `Unexpected end of JSON input` และ 500 ระหว่าง Fast Refresh แต่ไม่เกิดซ้ำในการตรวจรอบนี้

ผลตรวจอัตโนมัติ: ชุดทดสอบเฉพาะ 4 ไฟล์ผ่าน 19 tests และ `npm run typecheck` ผ่าน

หน้าอื่นที่อยู่ในขอบเขตการตรวจรอบนี้ตรวจครบแล้ว ไม่มีหน้าที่ยังค้างการตรวจ
