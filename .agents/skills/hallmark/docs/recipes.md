# Hallmark recipes (human reference)

Eight worked briefs for human readers. **Not auto-loaded by the skill** — agents follow `SKILL.md` directly.

This install bundles the skill protocol under `.agents/skills/hallmark/` without the upstream demo site. For live examples, run Hallmark on a scratch page in a non-ERP project or consult the per-theme specs in `references/themes/`.

## Sample brief shapes

1. **SaaS observability** — B2B dev tool · Stat-Led or Workbench · Coral or Cobalt · demo-video enrichment optional
2. **Bakery / café** — Local retail · Letter or Long Document · Garden or custom archival warmth · hand-built SVG illustration
3. **Studio manifesto** — Agency polemic · Manifesto · Brutal or Manifesto theme · typography only
4. **Docs home** — Reference product · Index-First or Almanac tone · Terminal or Cobalt · side-rail nav
5. **Consumer habit app** — Playful onboarding · Bento or Feature Stack · Hum · character motion
6. **AI tool landing** — Atmospheric · Marquee Hero · Bloom or Lumen · apparatus enrichment
7. **Portfolio grid** — Designer home · Portfolio Grid · Studio or Editorial · photographic optional
8. **Subscription letter** — Editorial intimacy · Letter · custom tuned palette · no hero enrichment

Each recipe is a **shape hint**, not a template. Macrostructure, nav, footer, and theme must still pass diversification and slop-test gates.
