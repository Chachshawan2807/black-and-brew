# Hallmark study examples (human reference)

Three worked DNA-extraction walkthroughs for human readers. **Not auto-loaded by the skill** — agents load [`references/study.md`](../references/study.md) when `hallmark study` runs.

This install does not bundle upstream screenshot captures or live demo URLs. Use `hallmark study` on your own reference (screenshot or public URL) and follow the structured-fields schema in `study.md`.

## Example outcomes (abbreviated)

### 1 · Editorial specimen page (image mode)

- **Macrostructure:** Specimen
- **Nav / footer:** N6 masthead · Ft4 dense colophon
- **Type roles:** high-contrast serif display · serif body · mono labels
- **Paper / accent:** light warm paper · warm accent ~35°
- **Carry over:** asymmetric spans, hairline rules, typographic CTA
- **Do not carry over:** invented metrics, centered hero template, gradient blobs

### 2 · Modern-minimal SaaS (URL mode)

- **Macrostructure:** Marquee Hero or Workbench
- **Nav / footer:** N1b three-section · Ft2 inline rule
- **Observed fonts:** (exact names from page CSS when URL mode succeeds)
- **Paper / accent:** cool light paper · single signal accent
- **Rhythm blind spot:** URL mode cannot judge vertical rhythm — offer screenshot fallback

### 3 · Atmospheric AI tool (image mode)

- **Macrostructure:** Stat-Led or Split Studio
- **Nav / footer:** N5 floating pill · Ft5 statement
- **Type roles:** grotesk or classical display · sans body
- **Paper / accent:** dark or tinted paper · cool or brass accent
- **Carry over:** apparatus or clipped demo, generous negative space
- **Do not carry over:** purple gradient hero, fake browser chrome, italic display headings

For the full protocol, refusal lists, and emission rules, see [`references/study.md`](../references/study.md).
